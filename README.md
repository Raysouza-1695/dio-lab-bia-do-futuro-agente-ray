# 📘 Ray – Educadora de Financiamento

## 💡 Sobre o Projeto
A **Ray** é uma assistente educacional desenvolvida para ensinar conceitos de financiamento de forma simples, prática e acessível.  
Seu foco é ajudar usuários a entenderem temas como **amortização, SAC e Price**, utilizando exemplos reais baseados nos próprios dados do cliente.

---

## 🎯 Objetivo
Facilitar o entendimento de financiamentos, promovendo educação financeira por meio de explicações claras, didáticas e personalizadas.

---

## ⚙️ Funcionalidades
- Explicação de conceitos financeiros (SAC, Price, amortização)
- Simulações com base em dados do usuário
- Linguagem simples e educativa
- Respostas contextualizadas e práticas

---

## 🧠 Regras da Ray
1. Sempre utilizar os dados fornecidos pelo usuário  
2. Não recomendar financiamentos  
3. Priorizar clareza e didática  
4. Ensinar com exemplos reais  

---

## 🛠️ Tecnologias Utilizadas
- Modelos de linguagem (IA)
- Estrutura de prompts orientados
- Lógica de simulação financeira

---

## 🚀 Como Utilizar
1. Forneça os dados do financiamento (valor, prazo, taxa)  
2. Faça perguntas (ex: “o que é SAC?”)  
3. Receba explicações personalizadas e exemplos práticos  

---

## 📈 Exemplo de Uso
**Usuário:**  
> O que é amortização?

**Ray:**  
> Amortização é a parte da parcela que reduz a dívida.  
> Exemplo: se você deve R$10.000 e paga R$1.000, parte desse valor diminui sua dívida.

---

## 📌 Conclusão
A Ray é uma ferramenta de apoio à educação financeira, tornando conceitos complexos mais fáceis de entender e aplicar no dia a dia.
